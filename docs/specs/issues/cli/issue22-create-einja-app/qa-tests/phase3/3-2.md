## 検出問題

### 🐛 重大な問題: {{packageName}}プレースホルダーの置換エラー

**問題ID**: ISSUE-3.2-002

**重要度**: 🔴 Critical（ブロッカー）

**概要**:
`src/generators/template.ts`の変数置換ロジックで、`{{packageName}}/`パターンが正しく置換されず、生成されたプロジェクトで型チェックエラーが発生する。

**原因分析**:

`template.ts`の`replacePlaceholders`関数（69-88行目）:
```typescript
// 78-79行目: {{packageName}} を @repo に置換
result = result.replaceAll("{{packageName}}", variables.packageName);

// 84-85行目: @repo/ を @repo/ に置換（意味なし）
result = result.replaceAll("@repo/", `${variables.packageName}/`);
```

しかし、テンプレート更新時（`template-update.ts`）に既に`@repo/`を`{{packageName}}/`に変換済み:
```typescript
// template-update.ts 113-116行目
return content.replace(
  /from\s+["']@repo\//g,
  'from "{{packageName}}/'
);
```

このため、79行目で`{{packageName}}`は`@repo`に置換されるが、`{{packageName}}/`パターンは置換されない（85行目は`@repo/`パターンを探すため）。

**再現手順**:
1. `pnpm -F create-einja-app build`を実行
2. テンプレートからプロジェクトを生成
3. `pnpm typecheck`を実行
4. `{{packageName}}/ui/utils`などのインポートエラーが発生

**期待される動作**:
```typescript
// テンプレート内
import { Button } from '{{packageName}}/ui/button';

// 生成後
import { Button } from '@repo/ui/button';
```

**実際の動作**:
```typescript
// テンプレート内
import { Button } from '{{packageName}}/ui/button';

// 生成後（置換されない）
import { Button } from '{{packageName}}/ui/button';  // ❌ エラー
```

**影響範囲**:
- AC-001-3: pnpm devが起動できない
- 型チェックエラー: 全てのimport文で`{{packageName}}/`を使用している箇所
- プロジェクト生成後の全ての開発作業がブロックされる

**推奨される修正方針**:

**方針A（推奨）**: `replacePlaceholders`関数を修正して、`{{packageName}}/`パターンも置換する

```typescript
// template.ts 78-79行目を修正
// 修正前
result = result.replaceAll("{{packageName}}", variables.packageName);

// 修正後（順序重要：長いパターンを先に置換）
result = result.replaceAll("{{packageName}}/", `${variables.packageName}/`);
result = result.replaceAll("{{packageName}}", variables.packageName);
```

**方針B**: 84-85行目の`@repo/`置換を削除（不要）

```typescript
// 削除対象
result = result.replaceAll("@repo/", `${variables.packageName}/`);
```

**関連ファイル**:
- `packages/create-einja-app/src/generators/template.ts`（78-85行目）
- `packages/create-einja-app/scripts/template-update.ts`（113-116行目）
