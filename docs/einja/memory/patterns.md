# 再利用パターン（Patterns）

このファイルには、プロジェクトで発見・確立された再利用可能なパターン（How）を記録します。

## 運用ルール

- **最大エントリ数**: 30件
- **上限到達時**: 古いエントリを `archive/patterns-{年}.md` に移動
- **エントリ形式**: 以下のテンプレートに従う

### エントリテンプレート

```markdown
## [YYYY-MM-DD] パターン名
- **問題**: どのような問題を解決するか
- **解法**: どのように解決するか
- **適用条件**: このパターンを使うべき状況
- **非適用条件**: このパターンを使うべきでない状況
- **例**: 具体的なコード例やユースケース
```
