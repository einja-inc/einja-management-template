# 意思決定記録（Decisions）

このファイルには、プロジェクトにおける重要な意思決定（Why）を記録します。

## 運用ルール

- **最大エントリ数**: 30件
- **上限到達時**: 古いエントリを `archive/decisions-{年}.md` に移動
- **エントリ形式**: 以下のテンプレートに従う

### エントリテンプレート

```markdown
## [YYYY-MM-DD] タイトル
- **結論**: 1-2文で結論
- **理由**: 簡潔な理由
- **見直し条件**: この決定を見直すべき条件
```
