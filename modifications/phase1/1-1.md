## 実装メモ

### パッケージ設定（package.json）
- **パッケージ名**: create-einja-app（スコープなし）
- **型**: ESM形式（"type": "module"）
- **bin**: ./dist/cli.js を create-einja-app コマンドとして登録
- **files**: dist、templates を配布対象に指定
- **engines**: Node.js 20.0.0以上を要求
- **publishConfig**: npm公開時に public アクセスを設定

### 依存関係
**dependencies**:
- chalk ^5.3.0 - カラー出力

### npm scripts
- `prebuild`: テンプレート更新（自動実行）
- `build`: tsupビルド
- `dev`: tsupウォッチモード
- `typecheck`: 型チェック
- `lint`: BiomeLint
- `test`: Vitest実行
- `template:update`: テンプレート更新（手動実行）
- `prepublishOnly`: npm publish前ビルド

### TypeScript設定（tsconfig.json）
- **target**: ES2022
- **module**: ESNext
- **moduleResolution**: bundler
- **strict**: true（厳格モード）
- **outDir**: ./dist
- **rootDir**: ./src
- **declaration**: true（型定義生成）

### tsup設定（tsup.config.ts）
- **entry**: src/cli.ts
- **format**: ESM形式
- **dts**: 型定義ファイル生成
- **clean**: ビルド前クリーン
- **shims**: Node.js shim追加
- **banner.js**: "#!/usr/bin/env node"（CLIシバン）

### CLIエントリーポイント（cli.ts）
- **Commanderによる実装**: コマンド登録、オプションパース
- **バージョン情報**: package.jsonから動的に読み込み
- **createコマンド**: プロジェクト作成（プレースホルダー実装）
  - 引数: [project-name]
  - オプション: --template, --skip-git, --skip-install, -y/--yes
- **setupコマンド**: 既存プロジェクトツール追加（プレースホルダー実装）

### 技術的な決定事項
1. **ESM形式の採用**: モダンなJavaScriptモジュール形式を使用
2. **tsupによるビルド**: 高速でシンプルなビルドツール
3. **Commanderによるコマンド管理**: 実績のあるCLIフレームワーク
4. **prebuildフックの活用**: ビルド前のテンプレート更新を自動化
5. **型安全性の保証**: TypeScript strict modeで厳格な型チェック
