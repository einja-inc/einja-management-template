# Skillユースケースカテゴリ＆デザインパターン

Anthropic公式ガイドに基づくSkill設計の参照資料。

## ユースケースカテゴリ

### 1. Document & Asset Creation
ファイルの生成・変換・編集を行うSkill。

**特徴**:
- 明確な入力→出力の変換がある
- テストケースで客観的に検証しやすい
- scripts/にヘルパーツールをバンドルすることが多い

**例**: PDF操作、DOCX生成、画像変換、コード生成

### 2. Workflow Automation
複数ステップのプロセスを自動化するSkill。

**特徴**:
- 決定ツリーや条件分岐が含まれる
- 複数のツール/MCPを連携させる
- エラーハンドリングとフォールバックが重要

**例**: CI/CDパイプライン、デプロイ自動化、データパイプライン

### 3. MCP Enhancement
MCPサーバーの機能を拡張・特化させるSkill。

**特徴**:
- 特定のMCPサーバーに依存
- ドメイン知識でMCPの汎用ツールを特化させる
- compatibilityフィールドで依存関係を明示

**例**: Figma連携強化、Slack自動化、データベース操作特化

## デザインパターン

### 1. Sequential Workflow（順次ワークフロー）
ステップバイステップで処理を進めるパターン。

```
ステップ1 → ステップ2 → ステップ3 → 完了
```

**適用場面**: 明確な順序がある処理、パイプライン
**SKILL.md構造**: ワークフロー決定ツリー → 各ステップの詳細

### 2. Multi-MCP Coordination（マルチMCP連携）
複数のMCPサーバーを組み合わせるパターン。

```
MCP-A（データ取得）→ 変換処理 → MCP-B（出力）
```

**適用場面**: 異なるサービス間のデータ連携
**注意点**: 各MCPの利用可能性チェックが必要

### 3. Iterative Refinement（反復改善）
出力を段階的に改善するパターン。

```
初回生成 → 評価 → 改善 → 再評価 → ... → 完了
```

**適用場面**: 品質が重要な出力（文章、デザイン、コード）
**注意点**: 終了条件を明確に定義する

### 4. Context-aware Tool Selection（コンテキスト適応ツール選択）
入力に応じて使用するツールを動的に選択するパターン。

```
入力分析 → ツール選択（A or B or C）→ 実行
```

**適用場面**: 多様な入力を処理するSkill
**SKILL.md構造**: 決定ツリーで選択基準を明示

### 5. Domain-specific Intelligence（ドメイン特化知識）
特定ドメインの専門知識をモデルに提供するパターン。

```
ドメイン知識（references/）→ 専門的な判断 → 出力
```

**適用場面**: 法務、財務、医療等の専門分野
**SKILL.md構造**: 概要 + references/に詳細ドキュメント
