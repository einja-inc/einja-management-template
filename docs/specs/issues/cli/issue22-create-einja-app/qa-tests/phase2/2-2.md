## 検出問題

### 問題1: fs-extraのESMインポートエラー

| 項目 | 内容 |
|------|------|
| 問題ID | F1 |
| 重大度 | 🔴 **CRITICAL** |
| カテゴリ | ビルド設定・依存関係 |
| 影響範囲 | 全ての受け入れ基準（AC-001-1, AC-009-2, AC-009-3, AC-011-2） |

**問題詳細**:
- `src/generators/template.ts` で fs-extra を named imports で読み込んでいる
- fs-extra v11はCommonJSモジュールであり、ESM環境では named exports をサポートしていない
- `package.json` に `"type": "module"` が設定されているため、Node.jsはESMとして解釈
- 実行時に `SyntaxError: Named export 'copySync' not found` が発生

**再現手順**:
```bash
cd /tmp
rm -rf test-project
node packages/create-einja-app/dist/cli.js test-project --yes
# SyntaxError発生
```

**推奨修正案1**: fs-extraをデフォルトインポートに変更

```typescript
// 修正前
import { copySync, readFileSync, writeFileSync, existsSync, removeSync } from "fs-extra";

// 修正後
import fsExtra from "fs-extra";
const { copySync, readFileSync, writeFileSync, existsSync, removeSync } = fsExtra;
```

**推奨修正案2**: Node.js標準のfs/promisesを使用（推奨）

```typescript
// 修正前
import { copySync, readFileSync, writeFileSync, existsSync, removeSync } from "fs-extra";

// 修正後
import { cp, readFile, writeFile, rm } from "node:fs/promises";
import { existsSync } from "node:fs";

// 使用箇所も非同期処理に変更
await cp(templatePath, targetPath, { recursive: true });
```

**影響箇所**:
- `src/generators/template.ts`
- `src/utils/fs.ts`（同様のインポートがある場合）
