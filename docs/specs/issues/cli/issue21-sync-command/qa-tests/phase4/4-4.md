### AC11.2: 標準出力・標準エラー出力の分離

#### テストケース: JSON形式の結果は標準出力、ログメッセージは標準エラー出力に分離される

**実行コマンド**:
```bash

```

**期待結果**:
- JSON形式の結果は標準出力（stdout）に出力される
- ログメッセージ（進捗表示など）は標準エラー出力（stderr）に出力される

**実行結果**: ✅ **PASS**
