# シナリオテスト

## 概要
このファイルは、複数タスクをまたぐ継続操作のシナリオテストを定義します。
各タスク完了後に、該当するシナリオテストを実行してください。

---

## シナリオ1: マジックリンク認証フロー

### 目的
ユーザーがメールアドレスを入力してマジックリンクをリクエストし、メール内のリンクをクリックしてログイン完了までの一連のフローを検証する。

### 関連
- **受け入れ条件**: Story 1 の全AC（AC1.UI.N.001, AC1.UI.N.002, AC1.VAL.E.001, AC1.VAL.E.002, AC1.VAL.E.003, AC1.ERR.E.001, AC1.UX.N.001, AC1.UX.N.002, AC1.NAV.N.001）

### 実施タイミング
- **AC1.UI.N.001, AC1.VAL.E.001, AC1.ERR.E.001実装後**: Step 1-4まで（部分実行：API認証まで）
- **AC1.UI.N.002, AC1.VAL.E.002, AC1.VAL.E.003, AC1.UX.N.001, AC1.UX.N.002, AC1.NAV.N.001実装後**: 全Step（フル実行：UI実装完了）
- **全AC実装後**: 全Step（リグレッション：最終確認）

### テスト手順

| Step | 操作 | 確認項目 | 期待値 | 結果 |
|------|------|---------|--------|------|
| 1 | ログイン画面に移動 | 画面が表示される | メールアドレス入力フォームが表示される | - |
| 2 | メールアドレス入力: test@example.com | - | - | - |
| 3 | 送信ボタンをクリック | ローディング状態になる | ボタン無効化、スピナー表示 | - |
| 4 | - | API呼び出しが成功 | メール送信確認画面に遷移 | - |
| 5 | - | 送信先アドレスが表示される | test@example.comが表示 | - |
| 6 | 受信したメールのリンクをクリック | トークン検証画面に遷移 | ローディングスピナー表示 | - |
| 7 | - | 認証処理が完了 | ダッシュボードにリダイレクト | - |
| 8 | - | ログイン状態になる | ユーザー名またはアバターが表示される | - |

## シナリオ2: マジックリンク認証フロー

### 目的
受信したマジックリンクをクリックして検証画面を経由し、ダッシュボードへ自動ログインする一連のフローを検証する。

### 関連
- **受け入れ条件**: Story 2 の全AC（AC2.NAV.N.001, AC2.NAV.N.002, AC2.UX.N.001, AC2.UX.N.002, AC2.ERR.E.001, AC2.ERR.E.002, AC2.ERR.E.003, AC2.ERR.E.004, AC2.ERR.E.005, AC2.UI.N.001）

### 実施タイミング
- **AC2.NAV.N.001, AC2.ERR.E.001, AC2.ERR.E.002実装後**: Step 1-3まで（部分実行：トークン検証APIまで）
- **AC2.UX.N.001, AC2.UX.N.002, AC2.NAV.N.002, AC2.ERR.E.003, AC2.ERR.E.004, AC2.ERR.E.005, AC2.UI.N.001実装後**: 全Step（フル実行：UI実装完了）
- **全AC実装後**: 全Step（リグレッション：最終確認）

### テスト手順

| Step | 操作 | 確認項目 | 期待値 | 結果 |
|------|------|---------|--------|------|
| 1 | シナリオ1を実行してマジックリンクを受信した状態にする | メール受信済み | 送信完了画面が表示されている | - |
| 2 | 受信したメール内のマジックリンクをクリック | トークン検証画面に遷移 | ローディングスピナーと「認証しています...」メッセージが表示される | - |
| 3 | - | トークン検証が完了 | 「ログインしています...」のメッセージが表示される | - |
| 4 | - | 3秒以内にリダイレクト | ダッシュボードへ自動的にリダイレクトされる | - |
| 5 | - | ログイン状態になる | ユーザー名またはアバターが表示される | - |
| 6 | 期限切れトークンのリンクをクリック | エラー画面に遷移 | 「リンクの有効期限が切れています」と「新しいリンクを送信」ボタンが表示される | - |
| 7 | 使用済みトークンのリンクをクリック | エラー画面に遷移 | 「このリンクは既に使用されています」と「新しいリンクを送信」ボタンが表示される | - |
| 8 | エラー画面の「新しいリンクを送信」ボタンをクリック | ログイン画面に遷移 | 前回使用したメールアドレスがプリフィルされたログイン画面が表示される | - |

## シナリオ3: エラーハンドリングフロー

### 目的
各種エラーケース（無効なメールアドレス、期限切れトークン、使用済みトークン、無効トークン等）が適切にハンドリングされることを検証する。

### 関連
- **受け入れ条件**: AC1.VAL.E.001, AC1.VAL.E.002, AC1.VAL.E.003, AC1.ERR.E.001, AC2.ERR.E.001, AC2.ERR.E.002, AC2.ERR.E.003, AC2.ERR.E.004, AC2.ERR.E.005

### 実施タイミング
- **AC1.VAL.E.001, AC1.VAL.E.002, AC1.VAL.E.003, AC1.ERR.E.001実装後**: Step 1-3まで（部分実行：Story 1 APIエラーハンドリング）
- **AC2.ERR.E.001, AC2.ERR.E.002, AC2.ERR.E.003, AC2.ERR.E.004, AC2.ERR.E.005実装後**: 全Step（フル実行：Story 2 エラーUI含む）
- **全AC実装後**: 全Step（リグレッション：最終確認）

### テスト手順

| Step | 操作 | 確認項目 | 期待値 | 結果 |
|------|------|---------|--------|------|
| 1 | ログイン画面で空欄のまま送信 | バリデーションエラー | 「メールアドレスを入力してください」表示 | - |
| 2 | 不正な形式（test@）で送信 | バリデーションエラー | 「有効なメールアドレスを入力してください」表示 | - |
| 3 | 有効なメールで送信後、1分以内に再送信 | レート制限エラー | 429エラー、待機時間が表示される | - |
| 4 | 期限切れトークンでアクセス | 期限切れエラー画面に遷移 | 「リンクの有効期限が切れています」と「新しいリンクを送信」ボタンが表示される | - |
| 5 | 使用済みトークンで再アクセス | 使用済みエラー画面に遷移 | 「このリンクは既に使用されています」と「新しいリンクを送信」ボタンが表示される | - |
| 6 | 無効なトークンでアクセス | 無効エラー画面に遷移 | 「無効なリンクです」と「ログインページに戻る」ボタンが表示される | - |

## シナリオ4: セキュリティ通知フロー

### 目的
新しいデバイスからログインした際にセキュリティ通知が送信され、セッション無効化ができることを検証する。

### 関連
- **受け入れ条件**: Story 3 の全AC（AC3.UI.N.001, AC3.UI.N.002, AC3.UI.N.003, AC3.UI.N.004, AC3.NAV.N.001, AC3.NAV.N.002）

### 実施タイミング
- **AC3.UI.N.001, AC3.UI.N.002, AC3.UI.N.003実装後**: Step 1-3まで（部分実行：通知送信まで）
- **AC3.NAV.N.001, AC3.UI.N.004, AC3.NAV.N.002実装後**: 全Step（フル実行：セッション無効化含む）
- **全AC実装後**: 全Step（リグレッション：最終確認）

### テスト手順

| Step | 操作 | 確認項目 | 期待値 | 結果 |
|------|------|---------|--------|------|
| 1 | 新しいデバイス（別ブラウザ）でログイン | ログイン成功 | ダッシュボードに遷移 | - |
| 2 | - | セキュリティ通知メール受信 | 新規デバイスログインの通知メールが届く | - |
| 3 | ダッシュボード確認 | 通知バナー表示 | 「新しいデバイスからのログインを検出しました」 | - |
| 4 | メール内「セッション無効化」リンクをクリック | 確認画面表示 | 「このセッションを無効化しますか？」表示 | - |
| 5 | 「無効化する」ボタンをクリック | セッション無効化 | 「セッションを無効化しました」表示 | - |
| 6 | 無効化されたデバイスでページをリロード | ログアウト状態 | ログイン画面にリダイレクト | - |
