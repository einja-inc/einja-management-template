# Google Drive 手動アップロードガイド

## 1. 概要

Skill が出力する HTML（Google Docs 向け）および .pptx（Google Slides 向け）ファイルは、Google Drive にアップロードすると自動的に Docs / Slides 形式に変換されます。

現フェーズ（半自動 MVP）では、アップロード操作はユーザーがブラウザで実施します。

---

## 2. Google Docs 化手順（HTML → Google Docs）

### 標準手順

1. ブラウザで https://drive.google.com を開く（Google アカウントにログイン済みであること）
2. 左メニューの「新規」または「+」ボタンをクリックし、「ファイルのアップロード」を選択する
3. ファイル選択ダイアログで `docs/exports/{ファイル名}.html` を選択する
4. アップロード完了通知が画面右下に表示される
5. Drive 上にアップロードされた HTML ファイルを **右クリック** → 「アプリで開く」 → 「Google ドキュメント」を選択する
6. 自動的に Google Docs 形式に変換されて開く
7. 表示崩れがあれば手動で調整する（mermaid SVG は画像として表示され、編集不可）

### 代替手順（より簡単）

1. https://docs.google.com/document/u/0/ を開く
2. 「ファイル」 → 「開く」 → 「アップロード」タブを選択する
3. `.html` ファイルをドラッグ&ドロップする
4. 自動的に新規 Docs として開かれる

---

## 3. Google Slides 化手順（.pptx → Google Slides）

1. ブラウザで https://drive.google.com を開く
2. 「新規」 → 「ファイルのアップロード」 → `docs/exports/{ファイル名}.pptx` を選択する
3. アップロード完了後、ファイルをダブルクリックし「Google スライドで開く」を選択する
4. または、https://slides.google.com を開き「ファイル」 → 「開く」 → 「アップロード」タブで .pptx をドラッグ&ドロップする
5. 自動的に Google Slides 形式に変換される
6. レイアウト崩れがあれば手動で調整する

---

## 4. アップロード時の注意

- ファイルサイズ上限: HTML / .pptx ともに 100MB（実用上の問題なし）
- 変換処理は通常数秒〜数十秒で完了する
- 同名ファイルが既に Drive に存在する場合、重複アップロードになる（自動マージはされない）
- アップロード後の編集権限はアップロードしたアカウントが保持する
- 共有する場合: ファイルを右クリック → 「共有」で社内メンバー・特定ユーザーに権限付与できる

---

## 5. 既知の制限・回避策

| 制限 | 回避策 |
|------|--------|
| mermaid SVG が画像として表示され編集不可 | Google Docs 内で再作図が必要な場合は、原本 .md を修正して Skill を再実行することを推奨 |
| 複雑な CSS（`@page` 等）は Docs 変換で失われる | 印刷向けレイアウトが必要な場合は PDF 形式を使用する |
| コードブロックのシンタックスハイライトは Docs 変換で失われる | プレーンテキストとしては保持される |
| .pptx の Marp テーマ CSS は Slides で完全再現されない | レイアウトの微調整は Slides 側で実施する |

## 7. トラブルシューティング

| 症状 | 原因 | 対処 |
|------|------|------|
| アップロード後に Docs 変換できない | 元 HTML が壊れている | 出力 HTML をブラウザで直接開いて表示確認する |
| 画像が表示されない | data URI が大きすぎる（10MB 超） | 元 .md の mermaid 図を分割・簡略化する |
| 文字化けが発生する | UTF-8 以外のエンコーディング | 入力 .md のエンコーディングを確認する（UTF-8 必須） |
| .pptx のアップロードが Slides 形式にならない | .pptx の構造不整合 | marp-cli を最新版に更新する（`npm cache clean` 後に再インストール） |
