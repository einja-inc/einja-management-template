# タスクフォーマット簡易参照

**詳細は [タスク管理ガイドライン](../../../../docs/einja/steering/task-management.md) を参照**

## タスク階層

| 階層 | 番号形式 | Markdown形式 |
|------|---------|-------------|
| Phase | 1, 2, 3 | `### Phase 1: 名前` |
| タスクグループ | X.Y | `- [ ] 1.1 名前` |
| タスク | X.Y.Z | `  - 1.1.1 名前` |
| サブタスク | なし | `    - 内容` |

## メタデータ（タスク単位で必須）

```markdown
- 1.1.1 タスク名
  - サブタスク内容
  - **要件**: Story X
  - **依存関係**: なし
  - **完了条件**: [条件]（ACX.Xを満たす）
  - **対応設計**: design.md「セクション名」
  - **シナリオテスト**: なし（理由）
```

## 依存関係の書式

| 形式 | 例 |
|------|-----|
| なし | `**依存関係**: なし` |
| タスクグループ依存 | `**依存関係**: 1.1` |
| 複数依存 | `**依存関係**: 1.2, 1.3` |
| Phase依存 | `**依存関係**: Phase 1完了` |

**使用禁止形式**: `1.1完了`、`タスク1.1`
