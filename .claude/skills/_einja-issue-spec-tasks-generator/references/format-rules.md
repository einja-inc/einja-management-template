# タスクフォーマット簡易参照

**詳細は [タスク管理ガイドライン](../../../../docs/einja/steering/task-management.md) を参照**

## タスク階層

| 階層 | 番号形式 | Markdown形式 |
|------|---------|-------------|
| Phase | 1, 2, 3 | `### Phase 1: 名前` |
| タスクグループ | X.Y | `- [ ] 1.1 名前` |
| タスク | X.Y.Z | `  - 1.1.1 名前` |
| サブタスク | なし | `    - 内容` |

## メタデータ（タスク単位で必須）

```markdown
- 1.1.1 タスク名
  - サブタスク内容
  - **要件**: Story X
  - **実装AC**: AC1.UI.N.001, AC1.VAL.E.001
  - **依存関係**: なし
  - **完了条件**: [条件]（AC1.UI.N.001を満たす）
  - **対応設計**: design.md「セクション名」
  - **シナリオテスト**: なし（理由）
```

## 依存関係の書式

| 形式 | 例 |
|------|-----|
| なし | `**依存関係**: なし` |
| タスクグループ依存 | `**依存関係**: 1.1` |
| 複数依存 | `**依存関係**: 1.2, 1.3` |
| Phase依存 | `**依存関係**: Phase 1完了` |

**使用禁止形式**: `1.1完了`、`タスク1.1`

## よくある間違い（絶対禁止）

以下は過去の生成で発生した形式違反パターンです。**これらは全てバリデーションエラーになります。**

| NG パターン | 正しい形式 | 理由 |
|------------|-----------|------|
| `Task 1-1: タスク名` | `  - 1.1.1 タスク名` | `Task` プレフィックス・ハイフン区切りは禁止。番号はドット区切り |
| `Task 1.1.1 タスク名` | `  - 1.1.1 タスク名` | `Task` プレフィックス禁止 |
| `1.1.1 タスク名`（インデントなし） | `  - 1.1.1 タスク名` | タスクは必ず2スペース + `- ` でインデント |
| `要件: Story 1` | `    - **要件**: Story 1` | メタデータキーは `**太字**` 必須 |
| `- 要件: Story 1` | `    - **要件**: Story 1` | メタデータは4スペースインデント必須 |
| `## Phase 1: 名前` | `### Phase 1: 名前` | Phase見出しは `###`（h3）|
| `1.1 タスクグループ名` | `- [ ] 1.1 タスクグループ名` | チェックボックス `- [ ]` 必須 |
| メタデータ5項目のみ | 6項目全て記載 | `**実装AC**` も必須メタデータ |

### 構造の正しい例

```markdown
### Phase 1: フェーズ名

- [ ] 1.1 タスクグループ名
  **実行サブエージェント**: [frontend-coder]（任意）

  - 1.1.1 タスク名
    - サブタスク内容（任意）
    - **要件**: Story 1
    - **実装AC**: AC1.UI.N.001, AC1.VAL.E.001
    - **依存関係**: なし
    - **完了条件**: テスト通過（AC1.UI.N.001を満たす）
    - **対応設計**: design.md「セクション名」
    - **シナリオテスト**: なし（基盤構築タスク）
```
