# CLAUDE.md Planモードフロー短縮 + Planファイルセクション追加

## Context
Planモード時の必須フローが冗長（7ステップ + ツール使い分け説明ブロック）。短縮して6ステップにし、Planファイルの必須セクションに「並列実行計画」「リスク・不明点」を追加する。

## 変更内容

対象ファイル: `CLAUDE.md` (L68-103)

### 1. 「ツールの使い分け」ブロック削除 (L70-73)
委託ルールセクションで自明なため不要。

### 2. Planモード時の必須フロー短縮 (L68-96 → 7ステップ)

```markdown
### Planモード時の必須フロー
1. 計画策定に必要なSkillを選定する
   - 「委託ルール」の対応表やSkillリストを参照し、関連Skillがあれば読み込む
2. 問題・要件を調査する [`Explore`]
3. `docs/plans/` で類似Planを検索し、あれば参考にする
4. 実装・レビューで使うSkill/サブエージェントを選定し、planに記載
5. planファイルに計画を記述
6. リスク・不明点があればAskUserQuestionで確認する
7. ExitPlanMode で承認を得る
```

### 3. Planファイルの必須セクションに2項目追加 (L98-103)

```markdown
### Planファイルの必須セクション
- **Context**: なぜこの変更が必要か
- **現状**: 修正箇所周辺の現状仕様・実装
- **変更内容**: 推奨アプローチのみ記載（対象ファイルパス含む）
- **タスク概要**: ステップと使用するSkill/サブエージェントのリスト（実装・レビュー別）
- **並列実行計画**: 並列可能なサブエージェントと依存関係の整理
- **リスク・不明点**: 技術的リスク、ブロッカー候補、要確認事項
- **検証・動作確認方法**: 変更をどう検証するか
```
