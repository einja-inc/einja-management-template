### AC-002-2: 既存の設定ファイルがある場合、マージ・上書き・スキップを選択できる

**検証方法**: ユニットテスト（`tests/unit/commands/setup.test.ts`）

**検証結果**: ✅ PASS

**エビデンス**:
- 3つの競合戦略（merge/skip/overwrite）すべてを検証
- 各戦略で既存ファイルが正しく処理されることを確認

**テストケース**:
```typescript
// P5-004: マージ戦略の動作 (4テストケース)
it("競合戦略がmergeの場合、既存ファイルに追記される", async () => {
  // 既存の .envrc に "export EXISTING=value" を作成
  await fs.writeFile(path.join(testDir, ".envrc"), "export EXISTING=value\n");

  await execSetup({ conflictStrategy: "merge" });

  const content = await fs.readFile(path.join(testDir, ".envrc"), "utf-8");
  expect(content).toContain("export EXISTING=value"); // 既存内容が保持
  expect(content).toContain("dotenv_if_exists .env"); // 新しい内容が追加
});

// P5-005: 上書き戦略の動作 (3テストケース)
it("競合戦略がoverwriteの場合、既存ファイルが上書きされる", async () => {
  await fs.writeFile(path.join(testDir, ".envrc"), "export OLD=value\n");

  await execSetup({ conflictStrategy: "overwrite" });

  const content = await fs.readFile(path.join(testDir, ".envrc"), "utf-8");
  expect(content).not.toContain("export OLD=value");
  expect(content).toContain("dotenv_if_exists .env");
});

// P5-006: スキップ戦略の動作 (3テストケース)
it("競合戦略がskipの場合、既存ファイルが保持される", async () => {
  await fs.writeFile(path.join(testDir, ".envrc"), "export EXISTING=value\n");

  await execSetup({ conflictStrategy: "skip" });

  const content = await fs.readFile(path.join(testDir, ".envrc"), "utf-8");
  expect(content).toBe("export EXISTING=value\n"); // 変更なし
});
```

### AC-002-4: 既存ファイルを破壊せずにツールが追加される（マージモード時）

**検証方法**: ユニットテスト（`tests/unit/utils/conflict-strategy.test.ts`）

**検証結果**: ✅ PASS

**エビデンス**:
- マージロジックで既存内容が保持されることを確認
- 重複行が追加されないことを確認
- package.json のマージでスクリプトが正しく追加されることを確認

**テストケース**:
```typescript
it("既存内容が保持される", () => {
  const existing = "export EXISTING=value\n";
  const newContent = "dotenv_if_exists .env\n";

  const result = mergeContent(existing, newContent);

  expect(result).toContain("export EXISTING=value");
  expect(result).toContain("dotenv_if_exists .env");
});

it("重複行は追加されない", () => {
  const existing = "dotenv_if_exists .env\n";
  const newContent = "dotenv_if_exists .env\n";

  const result = mergeContent(existing, newContent);

  const matches = result.match(/dotenv_if_exists .env/g);
  expect(matches?.length).toBe(1); // 重複なし
});
```
