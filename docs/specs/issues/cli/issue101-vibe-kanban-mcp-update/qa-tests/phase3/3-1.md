- **問題**: `startTaskAttempt` 呼び出しのフォーマットが Biome ルールに違反
- **影響範囲**: `packages/cli/src/commands/task-loop/index.ts`
- **修正内容**:
  ```typescript
  // 修正前
  const attempt = await vibeKanban.startTaskAttempt(title, "CLAUDE_CODE", reposWithBranch, taskId);

  // 修正後
  const attempt = await vibeKanban.startTaskAttempt(
    title,
    "CLAUDE_CODE",
    reposWithBranch,
    taskId
  );
  ```
- **ステータス**: ✅ 修正済み
