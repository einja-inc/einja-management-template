## 環境問題の詳細

### 問題1: DATABASE_URL未設定

**発生事象**:
```
error: Environment variable not found: DATABASE_URL.
  -->  schema.prisma:10
```

**対処試行**:
1. .env.exampleを.envにコピー → 効果なし
2. 環境変数を明示的に設定して実行 → DB未起動エラーに変化
3. Vitestの環境変数読み込み設定が不足（vitest.config.ts）

**解決策**:
- vitest.config.tsに`dotenv`または`loadEnv`を追加
- または、vitest.setup.tsでprocess.env.DATABASE_URLを設定

### 問題2: PostgreSQL未起動

**発生事象**:
```
Can't reach database server at `localhost:5432`
```

**原因**:
- docker-compose up -d postgresが実行されていない
- またはポート5432でPostgreSQLが起動していない

**解決策**:
```bash
cd /path/to/project/root
docker-compose up -d postgres
```

### 問題3: Biome未インストール

**発生事象**:
```
sh: biome: command not found
```

**原因**:
- playground環境でBiomeがインストールされていない
- package.jsonのdevDependenciesに@biomejs/biomeが不在

**解決策**:
```bash
pnpm add -D @biomejs/biome
```
