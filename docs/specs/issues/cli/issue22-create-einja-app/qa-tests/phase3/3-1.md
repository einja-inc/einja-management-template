## 2. 型チェックエラー詳細

```
tests/unit/prompts/project.test.ts(135,12): error TS2532: Object is possibly 'undefined'.
tests/unit/prompts/project.test.ts(136,12): error TS2532: Object is possibly 'undefined'.
tests/unit/prompts/project.test.ts(137,12): error TS2532: Object is possibly 'undefined'.
```

**問題箇所**:
```typescript
expect(result.worktreeConfig?.apps[0].id).toBe("web");
expect(result.worktreeConfig?.apps[0].portRangeStart).toBe(3000);
expect(result.worktreeConfig?.apps[0].rangeSize).toBe(1000);
```

**原因**: `result.worktreeConfig?.apps[0]` が `undefined` の可能性があるため、型チェックエラー

**修正案**:
```typescript
expect(result.worktreeConfig?.apps).toHaveLength(1);
expect(result.worktreeConfig?.apps?.[0]?.id).toBe("web");
expect(result.worktreeConfig?.apps?.[0]?.portRangeStart).toBe(3000);
expect(result.worktreeConfig?.apps?.[0]?.rangeSize).toBe(1000);
```
