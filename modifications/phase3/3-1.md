## 実装メモ

### 使用した技術
- TypeScript 5.7.2
- Vitest 2.1.8（テストフレームワーク）
- tsup 8.3.5（ビルドツール）
- fs-extra、glob、inquirer等のユーティリティライブラリ

### 主要な実装内容

#### 1. 型定義システム
- `ConflictStrategy` - ファイル競合時の戦略（merge/overwrite/skip）
- `ToolConfig` - 環境ツールの有効/無効設定
- `ToolSetupOptions` - ジェネレーター共通オプション

#### 2. ファイル操作ユーティリティ（fs.ts）
- `writeWithStrategy()` - 競合戦略に基づくファイル書き込み
- `ensureDir()` - ディレクトリ作成（存在確認付き）
- `appendToGitignore()` - .gitignoreへの安全な追記

#### 3. package.json操作ユーティリティ（package-json.ts）
- `addScripts()` - npm scriptsの追加
- `addDependencies()` - 依存関係の追加
- `addVoltaField()` - Volta設定の追加
- `addLintStaged()` - lint-staged設定の追加

#### 4. 環境ツールジェネレーター
各ジェネレーターは要件定義書の受け入れ基準（AC）を満たすように実装：

**direnv.ts**:
- AC-003-1: .envrc生成（dotenv_if_exists設定）
- AC-003-2: .envrc.example生成
- AC-003-3: .gitignoreに.envrc追加

**dotenvx.ts**:
- AC-004-1: package.jsonに@dotenvx/dotenvx追加
- AC-004-2: env:encrypt, env:decryptスクリプト追加
- AC-004-3: .env.example生成

**volta.ts**:
- AC-005-1: package.jsonにvoltaフィールド追加（Node 22.16.0, pnpm 9.15.0）
- AC-005-2: .node-version生成

**biome.ts**（--setupモード用）:
- AC-006-1: biome.json生成（設定完備）
- AC-006-2: lint/formatスクリプト追加
- AC-006-3: VSCode設定追加（.vscode/settings.json）

**husky.ts**（--setupモード用）:
- AC-007-1: .huskyディレクトリ生成
- AC-007-2: pre-commitフック設定（pnpm lint-staged実行）
- AC-007-3: lint-staged設定追加（Biome実行）

#### 5. テスト戦略
- Given-When-Then形式のテスト記述
- tmpdir使用による隔離されたテスト環境
- 受け入れ基準（AC）に対応するテストケース
- 競合戦略（skip）のテストケース

### 重要な決定事項

1. **index.ts不使用方針の徹底**
   - 設計書通り、`generators/tools/index.ts`のみエクスポート用
   - ファイル追加時にpackage.json更新不要

2. **any型の完全排除**
   - 全ての関数に明示的な型注釈
   - TypeScript strict modeでコンパイル

3. **競合戦略の実装**
   - merge: 既存内容に追記
   - overwrite: 上書き
   - skip: 既存ファイルを保持

4. **バージョン固定**
   - Node.js: 22.16.0（要件定義書通り）
   - pnpm: 9.15.0
   - Biome: 1.9.4
   - Husky: 9.1.7

## レビュー指摘修正（2026-01-08）

### 概要
GitHub Issue #22 タスクグループ 3.1のレビュー指摘事項（MAJOR判定）を修正しました。

### 修正内容

#### MAJOR-3: TypeScript設定ファイルの作成

**問題**: `packages/create-einja-app/tsconfig.json`が`"extends": "../config/typescript/base.json"`を参照しているが、ファイルが存在しない

**対処**: `packages/config/typescript/base.json`を新規作成

**新規作成ファイル**:
- `packages/config/typescript/base.json`
  - Node.js CLIツール向けの基本TypeScript設定
  - ES2022ターゲット、strictモード有効
  - モジュール解決: bundler（TSモジュール解決の最新方式）

#### MAJOR-2: Biome Lintエラー修正

**問題**: `packages/create-einja-app/src/utils/fs.ts` line 27-28
- `lint/correctness/noSwitchDeclarations` エラー
- switch case内での変数宣言が他のcaseからアクセス可能になる問題

**対処**: 各case節をブロック`{}`で囲む

**修正ファイル**:
- `packages/create-einja-app/src/utils/fs.ts`
  - `case "overwrite":`、`case "merge":`、`case "skip":`の各節をブロックスコープ化
  - 変数のスコープを適切に分離

#### MAJOR-1: tsconfig.jsonの設定修正

**問題**: `rootDir: "./src"`が設定されているが、`include`に`tests/**/*`が含まれていてエラー
- エラー: `File 'tests/unit/generators/tools/*.test.ts' is not under 'rootDir' './src'`

**対処**: `rootDir`オプションを削除

**修正ファイル**:
- `packages/create-einja-app/tsconfig.json`
  - `compilerOptions.rootDir`を削除
  - TypeScriptがsrc/とtests/の両方を適切に認識
