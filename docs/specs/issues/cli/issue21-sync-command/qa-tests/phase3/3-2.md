# QAテスト仕様書: タスクグループ3.2 JSON出力オプション

## 機能名: JSON出力オプション
- **背景/価値**: CLIの出力をJSON形式で取得することで、他のツールやスクリプトとの連携が容易になる
- **関連AC**: AC8.1, AC8.2, AC8.3
- **テスト範囲**: Integration

---

## テストシナリオ

### シナリオ1: AC8.1 - JSON形式でのstdout出力

**前提条件（Given）**:
- CLIがビルドされている
- テスト用プロジェクトが存在する

**操作（When）**:
```bash
cd /tmp/qa-test-3-2
npx @einja/cli sync --json 2>/tmp/qa-test-stderr.txt 1>/tmp/qa-test-stdout.txt
```

**期待結果（Then）**:
- stdout（/tmp/qa-test-stdout.txt）にJSON形式で出力される
- JSONは以下の構造を持つ:
  ```json
  {
    "status": "success" | "partial_success" | "failure",
    "summary": {
      "total": number,
      "changed": number,
      "succeeded": number,
      "conflicts": number,
      "skipped": number
    },
    "files": [...],
    "metadata": {
      "version": string,
      "syncedAt": string
    }
  }
  ```

**確認方法**:
```bash
cat /tmp/qa-test-stdout.txt | jq .
```

---

### シナリオ2: AC8.2 - コンフリクト発生時のconflicts配列

**前提条件（Given）**:
- CLIがビルドされている
- テスト用プロジェクトが存在する
- ローカルファイルがテンプレートと異なる内容に変更されている

**操作（When）**:
```bash
# ローカルファイルを変更してコンフリクトを発生させる
echo "変更されたコンテンツ" > .claude/commands/einja/start-dev.md

# .einja-sync.jsonを削除して再同期
rm .einja-sync.json

# JSON形式で同期実行
npx @einja/cli sync --json 2>/tmp/qa-test-stderr3.txt 1>/tmp/qa-test-stdout3.txt
```

**期待結果（Then）**:
- JSONのfilesの中にコンフリクトしたファイルが含まれる
- コンフリクトしたファイルは以下の構造を持つ:
  ```json
  {
    "path": "...",
    "status": "conflict",
    "action": "marked",
    "conflicts": [
      {
        "line": number,
        "local": string,
        "template": string
      }
    ]
  }
  ```

**確認方法**:
```bash
cat /tmp/qa-test-stdout3.txt | jq '.files[] | select(.status == "conflict")'
```

---

### シナリオ3: AC8.3 - ログはstderr、JSONはstdoutのみ

**前提条件（Given）**:
- CLIがビルドされている
- テスト用プロジェクトが存在する

**操作（When）**:
```bash
npx @einja/cli sync --json 2>/tmp/qa-test-stderr.txt 1>/tmp/qa-test-stdout.txt
```

**期待結果（Then）**:
- stderr（/tmp/qa-test-stderr.txt）にはスピナーメッセージやログが出力される
- stdout（/tmp/qa-test-stdout.txt）にはJSONのみが出力される

**確認方法**:
```bash
# stderrにログが含まれることを確認
grep -q "テンプレート同期を開始" /tmp/qa-test-stderr.txt && echo "PASS" || echo "FAIL"

# stdoutがJSONのみであることを確認
cat /tmp/qa-test-stdout.txt | jq . > /dev/null && echo "PASS" || echo "FAIL"
```
