### 設計判断の記録

**判断**: 内部形式（`"inprogress"`）を維持し、MCP通信層で変換を行う

**理由**:
1. 内部コード（`index.ts`）で`"inprogress"`を使用している箇所がある
2. 全ての内部コードを`"in-progress"`に変更するより、通信層で変換する方が変更箇所が少ない
3. 後方互換性を維持できる

**影響**:
- 型定義では両方の形式を許容（`"inprogress" | "in-progress"`）
- MCP通信では正しい形式（`"in-progress"`）を使用
