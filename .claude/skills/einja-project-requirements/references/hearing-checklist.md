# ヒアリングチェックリスト（einja-project-requirements）

本ファイルは `einja-project-requirements` Skill が AskUserQuestion で使う質問テンプレ集である。
**Plan 確定章立て §1-§16 に 1:1 対応** する 4 ラウンド構成。

## 使用上の原則

- **1 ラウンド = 3-5 質問グループ**（深さ優先より広さ優先）
- **選択肢は 2-4 個**（4 個超は別 Q に分割）
- **「その他（自由入力）」を必ず含める**（CLAUDE.md 準拠）
- **「決まっていない / 未定」も明示的に選択肢に含める**（推測禁止）
- **ビジネス判断に集中**: 技術的事実（既存実装・API 仕様）は事前調査で吸収済みの前提
- **ラウンド連動**: 後ラウンドの回答で前ラウンドの確認が必要になった場合は **追加 1 回までさかのぼり確認** してよい
  - 例: Round 4 で「24/365 運用」と回答 → Round 3 の性能・可用性目標を再確認
- **`description` (What) と `Note:` (So What) の 2 層記述** で選択肢を提示する
